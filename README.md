# ☕ Laboratório de Estudos: Java Completo e Programação Orientada a Objetos

Este repositório serve como o meu laboratório central de estudos e práticas diárias durante o curso **Java Completo Programação Orientada a Objetos**, ministrado pelo Professor Nélio Alves. Aqui, documento toda a minha evolução na linguagem, fixação de conceitos arquiteturais e resolução de desafios e exercícios de fixação.

Os projetos de maior robustez de negócio e refatorações complexas que nasceram neste laboratório foram movidos para repositórios independentes para melhor visualização de portfólio.

---

## 📂 Estrutura de Aprendizado e Módulos

O repositório é organizado de forma cronológica, acompanhando a evolução da grade curricular do curso e os meus estudos independentes:

* **Fundamentos da Linguagem:** Práticas iniciais de lógica, estruturas condicionais (`if-else`), estruturas de repetição (`while`, `for`) e manipulação de arrays e matrizes.
* **Programação Orientada a Objetos (POO):** Exercícios de fixação focados na criação de classes, atributos, métodos, construtores, sobrecarga e o uso estrito de encapsulamento.
* **Comportamento de Memória, Arrays e Listas:** Laboratórios abordando tipos referência vs. tipos valor, desalocação de memória (Garbage Collector), Boxing, Unboxing e a manipulação avançada de listas.
* **Tópicos Especiais em Java:** Trabalhando com formatação e manipulação de datas e horas (padrões ISO 8601).
* **Enumerações e Composição:** Exercícios práticos aplicando a arquitetura de composição de objetos para modelagem de cenários reais do mercado.
* **Herança e Polimorfismo:** Implementação de reaproveitamento de código através de herança, sobreposição de métodos (`@Override`), classes e métodos abstratos.
* **Tratamento de Exceções:** Fixação do uso do bloco `try-catch` e a estrutura de propagação de erros em tempo de execução.
* **Persistência e Banco de Dados (Em Andamento):** Módulo dedicado à integração do ecossistema Java com bancos de dados relacionais (SQL) utilizando **JDBC** (Java Database Connectivity).

* **Linguagem:** Java (JDK 17 / 21)
